# UK Taxi PHV Regulatory Decision Layer

Deterministic taxi and private-hire regulatory preflight decisions for licensing and compliance workflows in England.

## Remote MCP endpoint

`https://uk-taxi-phv-mcp-production.up.railway.app/mcp`

## Use

This repository is the public documentation surface for the hosted MCP server. The production implementation is hosted separately; this repository does not publish private application source code.

The server is intended for evidence-linked regulatory preflight and structured decision support. It does not imply endorsement by any regulator or public body.
